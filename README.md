# Sistema de Gestión - Hospital Veterinario (POO en Java)

Sistema de consola desarrollado en Java (JDK 17 o superior) para la gestión de pacientes, jaulas y reglas de negocio de una clínica veterinaria, implementado estrictamente con vectores de capacidad fija y principios de Programación Orientada a Objetos.

## 🛠️ Especificaciones Técnicas
- **Lenguaje:** Java (JDK 17+)
- **Almacenamiento:** Vectores de capacidad fija (`Paciente[]` y `Jaula[]`), sin colecciones externas (`ArrayList`, etc.) ni bases de datos.
- **Arquitectura:** Estricta separación entre el Dominio (clases lógicas sin `Scanner` ni `System.out`) y la Capa de Interacción (`Main`).
- **Encapsulamiento:** Atributos privados con validaciones estrictas en *setters*.
